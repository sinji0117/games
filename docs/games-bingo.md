# 빙고 게임 (설계 초안 · 4단계)

## 규칙
- 판 크기 N×N (기본 5, 3~7). 숫자 빙고(1~N²×2 범위) 또는 단어 빙고(방장이 단어 목록 제공).
- 방장이 방을 만들고, 참가자는 무작위 판 또는 직접 배치한 판으로 참가.
- 진행 방식 두 가지
  - **서버 추첨**: 서버가 시드 기반으로 미리 섞은 순서대로 일정 간격 공개 (사다리와 같은 commit-reveal)
  - **턴 호출**: 참가자가 차례대로 번호를 부름
- 목표 줄 수(1~N+2줄, 가로·세로·대각선)를 먼저 완성한 사람이 승리. 동시 완성은 공동 승리.

## 엔진 설계 (`crates/core/src/games/bingo.rs`)
- `Board { size, cells: Vec<Cell>, marked: u64 비트마스크 }` — 7×7=49 칸까지 u64 하나로 표현
- 줄 마스크를 미리 계산(가로 N + 세로 N + 대각 2)해 `marked & line == line` 개수로 줄 수 판정 → O(2N+2)
- 판 검증: 중복 값 금지, 범위 확인
- 추첨 순서: `SeededRng::shuffle`

## 상태 동기화
- 방 상태는 Redis `game:bingo:{id}` 에 저장, 호출된 번호는 리스트로 누적
- 이벤트(`called`, `bingo`, `finished`)는 Pub/Sub 으로 방송 → `redis-pubsub.md`
