# 빙고 게임

## 규칙
- 판 크기 N×N (3~7, 기본 5). 칸 `i` 는 `(행 i / N, 열 i % N)`.
- 채울 값(풀): 숫자 `1..=max` (`max` 는 N² ~ 150, 기본 N²) 또는 방장이 정한 단어 N² ~ 150개 (각 12자 이하, 중복 불가).
- 방을 만든 사람이 0번 참가자이자 방장. 링크로 들어온 사람은 이름(20자 이하, 중복 불가)을 적고 참가 (최대 30명).
- 시작 전에는 각자 판을 섞거나 두 칸을 바꿔 배치할 수 있음. 기본 판은 시드에서 정해짐.
- 2명 이상이면 방장이 시작.
- 진행 방식
  - **번호 뽑기**(`draw`): 방장이 누를 때마다 시드로 미리 섞어 둔 순서대로 하나씩 공개.
  - **돌아가며 부르기**(`turns`): 참가 순서대로 아직 안 불린 값을 하나씩 부름. 끝날 때까지 다른 사람의 판은 보이지 않음.
- 줄: 가로 N + 세로 N + 대각선 2 = 2N+2 개. 목표 줄 수(1 ~ 2N+2, 기본 N)를 먼저 채우면 승리.
- 한 번 부를 때마다 판정하며, 같은 호출로 여럿이 목표에 닿으면 **공동 우승**. 승자가 나오면 즉시 종료.

## 엔진 (`crates/core/src/games/bingo.rs`)
| 항목 | 내용 |
| --- | --- |
| 값 표현 | 풀 인덱스 `u16`. 표시 문자열은 `labels[i]` |
| 판 | `Vec<u16>` N²개, 시작 시 중복·범위 검증 |
| 줄 판정 | 판을 `u64` 비트마스크(최대 49칸)로, `marked & line == line` 개수 |
| 줄 번호 | `0..N` 가로, `N..2N` 세로, `2N` ↘ 대각, `2N+1` ↙ 대각 |
| 추첨 순서 | `draw_order(seed, pool)` = 풀 전체를 `SeededRng(seed)` 로 Fisher–Yates |
| 기본 판 | `default_board(seed, i, pool, N)` = `seed ^ ((i+1) × 0xA24BAED4963EE407)` 로 섞은 앞 N² 개 |
| 저장 | `BingoSnapshot { config, players, started, calls }` + 시드. `restore` 가 모든 판·호출을 규칙대로 다시 적용(차례·추첨 순서 위반이면 거부) |

## 공정성
- 방을 만들 때 `commitment = sha256(seed:nonce)` 공개, 끝나면 시드·논스와 모든 판 공개.
- 브라우저 검증 (`apps/site/src/lib/bingo/verify.ts`)
  1. 해시 일치
  2. 번호 뽑기: 뽑힌 순서가 `draw_order(seed)` 의 앞부분과 같음
  3. 공개된 판으로 줄 수·승자를 다시 계산해도 같음
- 돌아가며 부르기는 사람이 고르므로 순서 검증 대상이 아님. 대신 남의 판을 미리 볼 수 없어 막기 위한 부르기가 불가능.

## 화면 (`apps/site/src/pages/bingo`)
- `BingoSetup`: 이름, 판 크기, 진행 방식, 숫자/단어, 이기는 줄 수
- `BingoRoom`: 참가 폼 → 시작 전 판 배치(섞기, 두 칸 눌러 바꾸기) → 진행(방장 "번호 뽑기" 또는 내 차례에 칸 누르기) → 끝(승자, 모든 판, 검증)
- 불린 칸은 도장, 완성된 줄은 펜 선. 방금 불린 칸만 짧게 도장 찍히는 움직임 (`prefers-reduced-motion` 이면 생략)
- 참가자 신원: `localStorage["bingo.player.{id}"] = { token, index }`. 다른 브라우저에서는 관전만 가능.

## 테스트
- Rust: 줄 마스크, 검증 규칙, 기본 판 결정성, 차례·중복·범위, 추첨 순서와 승자 판정(모든 크기), 동시 우승, 스냅샷 왕복·조작 거부, 단어 풀
- TS: 추첨 순서·기본 판·줄 마스크가 Rust 와 같음(`crates/core/examples/bingo_fixtures.rs` 기준값), 조작 검출
