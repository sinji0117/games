# 핀볼 룰렛 (마블 룰렛 형식)

[Marble Roulette](https://lazygyu.github.io/roulette/) 처럼 이름마다 구슬을 만들어 핀볼 맵에 굴리고, 도착 순서로 당첨자를 뽑습니다.
0.5.0 의 플리퍼 핀볼(점수 경쟁)은 0.6.0 에서 이 방식으로 바뀌었습니다.

## 규칙
- 이름: 쉼표나 줄바꿈으로 구분, `이름*개수` 로 구슬 개수 지정 (예: `수박*2, 키위, 귤*3`). 같은 이름은 개수를 합침
  - 이름 20자 이하, 한 이름 1~20개, 전체 2~100개
- 맵: **클래식**(핀 숲 → 풍차 2개 → 지그재그 경사 → 범퍼 → 좁은 관문 → 풍차, 20초 안팎) / **스프린트**(핀 숲 → 풍차 → 관문, 10초 안팎)
- 당첨: **먼저 도착**한 N명 또는 **마지막에 도착**한 N명 (1 ~ 구슬 수 − 1)
- 스킬 사용: 2초마다 달리는 구슬 하나가 무작위로 튀어 오름
- 10초 동안 아무도 도착하지 않으면 모든 구슬을 살짝 흔듦 (끼임 방지). 5분이 지나면 결승선에 가까운 순서로 순위 확정

## 공정성
1. 브라우저가 이름 목록·맵·당첨 기준을 보냄
2. **그 뒤에** 서버가 OS 난수로 시드를 뽑고, `pinball::run` 으로 경주를 끝까지 돌려 순위를 확정·저장
3. 시드가 출발 자리(섞기)와 스킬·흔들기를 모두 정하므로, 만드는 사람은 결과를 보고 고칠 수 없음
4. 브라우저(만든 사람과 공유 링크로 들어온 사람 모두)는 같은 시드로 경주를 재생하고, 끝난 순서가 서버 결과와 같은지 표시

한계: 같은 이름 목록으로 마음에 드는 결과가 나올 때까지 다시 만드는 것은 막지 못합니다. 모든 생성 기록이 `pinball_games` 에 남고 레이트 리밋(30회/분)이 걸려 있습니다. 6단계에서 방 단위 "한 번만 굴리기"를 넣을 수 있습니다.

## 결정성 (Rust `crates/core/src/games/pinball.rs` ↔ TS `apps/site/src/lib/pinball/engine.ts`)
- `+ - * /` 와 `sqrt` 만 사용. 풍차 회전은 256단계 방향 표(`rotation.rs` / `rotation.ts`, 같은 리터럴)로
- 두 구현은 줄 단위로 대응. 구슬 충돌은 (y, 번호) 로 정렬해 가까운 쌍만 같은 순서로 처리
- 난수는 `SeededRng` 로 정해진 순서(출발 자리 섞기 → 자리별 흔들림 → 스킬·흔들기)에만
- 바꾼 뒤: `cargo run -p game-core --example pinball_fixtures > apps/site/src/lib/pinball/tests/rust-fixtures.json` → `pnpm --filter @games/site test`

## 물리
| 항목 | 값 |
| --- | --- |
| 맵 | 가로 400, 세로 2400(클래식) / 1200(스프린트) |
| 틱 | 1/120초, 틱마다 3번 나눠 이동·충돌 |
| 구슬 | 반지름 8, 중력 0.1, 감쇠 0.998, 속도 상한 10 |
| 반발 | 벽 0.4, 핀 0.5, 구슬끼리 0.8, 풍차 0.5 + 날개 이동속도 |
| 범퍼 | 닿으면 바깥쪽으로 속도 5 |
| 핀 배치 | 벽과 바깥 핀 사이 틈 23 이상 (구슬 지름 16) — 좁으면 구슬이 핀 위에 걸쳐 멈춤 (테스트로 보장) |
| 출발 | 한 줄 16자리, 시드로 자리 섞고 ±1 흔들림 |

## 화면 (`apps/site/src/pages/pinball`)
- `PinballSetup`: 이름 입력, 목록 섞기, 맵·당첨·인원·스킬, 맵 미리보기. 마지막 설정을 기억함
- `PinballRace`: 선두 구슬을 따라가는 카메라, 미니맵, 실시간 도착 목록, 1·2·4배속, 결과 바로 보기, 당첨 발표, 서버 결과 일치 표시
- 이름별 색은 같은 이름끼리 같음. 구슬 40개 이하면 이름표 표시

## 테스트
- Rust: 회전 표, 이름 해석, 검증, 출발 자리, 두 맵 모두 시간 안에 전원 도착(스킬 유무), 100개 도착, 구슬이 맵 안에 머묾, 결정성·시드 의존, 당첨 기준, 출발 순서 유불리 없음(200판), 벽 옆 틈
- TS: Rust 기준값과 120틱마다 모든 구슬 위치·속도, 최종 순위·당첨·틱이 비트 단위로 같음, 이름 해석
- API: 서버 결과가 시드로 재현됨, 조회 결과 같음, 잘못된 설정 거부
