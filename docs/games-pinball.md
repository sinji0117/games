# 핀볼 게임 (테이블 v1)

## 핵심: 서버가 같은 게임을 다시 돌려 점수를 정함
명세 초안의 "Matter.js + 점수 이벤트·시퀀스 검증" 대신, **Rust 와 TS 에서 비트 단위로 같은 결과를 내는 작은 결정적 물리 엔진**을 직접 만들었습니다.

| | 이벤트 검증(초안) | 재시뮬레이션(채택) |
| --- | --- | --- |
| 서버가 받는 것 | 점수 이벤트 목록 | 입력 기록 (틱, 동작) 만 |
| 점수 조작 | "그럴듯한" 조작은 통과 가능 | 불가능 — 점수는 서버가 계산 |
| 필요 조건 | 물리 엔진 아무거나 | 두 언어에서 같은 결과 (테스트로 보장) |

1. `POST /api/pinball/sessions` → 서버가 시드를 정함 (발사 세기 ±3%, 범퍼 반동 ±10% 에 쓰임)
2. 브라우저는 같은 시드로 120Hz 고정 틱 시뮬레이션을 돌리며 입력을 `{ tick, action }` 으로 기록
3. 끝나면 이름과 입력 기록을 제출 → 서버가 `pinball::replay(seed, inputs)` 로 처음부터 다시 계산한 점수를 저장
4. 한 판에 한 번만 제출 가능, 시드가 판마다 달라서 좋은 입력 기록을 다른 판에 재사용해도 같은 점수가 나오지 않음

### 막는 것 / 못 막는 것
- 막음: 점수·이벤트 위조, 같은 판 여러 번 제출, 기록 재사용, 실제로 흐른 시간보다 긴 게임 제출(게임 시간 ≤ 경과 시간 ÷ 0.8)
- 못 막음: 시드를 받은 뒤 컴퓨터로 최적 입력을 찾아 실제 시간만큼 기다렸다 제출하는 방식(TAS). 시드를 숨기면 브라우저가 게임을 돌릴 수 없어서 생기는 한계입니다. 필요하면 6단계에서 계정·기기당 제출 빈도 제한과 이상치 검토를 더합니다.

## 결정성 규칙 (Rust `crates/core/src/games/pinball.rs` ↔ TS `apps/site/src/lib/pinball/engine.ts`)
- `+ - * /` 와 `sqrt` 만 사용 (IEEE 754 가 결과를 하나로 정함). `sin/cos/hypot/round` 금지 — 플리퍼 각도는 9단계 방향 표(`FLIPPER_DIRS`)를 두 언어에 같은 리터럴로 둠
- 두 구현은 줄 단위로 대응. 연산 순서·괄호를 바꾸면 안 됨
- 난수는 `SeededRng` 로 발사·범퍼 충돌 시점에만 꺼냄
- 바꾼 뒤에는 기준값을 다시 뽑고 TS 테스트로 확인:
  `cargo run -p game-core --example pinball_fixtures > apps/site/src/lib/pinball/tests/rust-fixtures.json` → `pnpm --filter @games/site test`

## 물리
| 항목 | 값 |
| --- | --- |
| 테이블 | 400 × 700 (y 아래로 증가) |
| 틱 | 1/120초, 틱마다 4번 나눠 이동·충돌 |
| 중력 / 감쇠 / 속도 상한 | 0.12 / 0.999 / 14 (단위/틱) |
| 공 | 반지름 9, 3개 |
| 벽 | 두께 2 캡슐, 반발 0.5 |
| 플리퍼 | 길이 56, 두께 6, 0~8 단계(틱당 1단계), 반발 0.3 + 접점 이동속도 |
| 슬링샷 | 반발 0.6 + 법선 방향 4 추가, 10점 |
| 범퍼 | 반지름 20, 법선 방향 6 × (0.9~1.1), 100점 |
| 고무 기둥 | 양쪽 벽 (44, 250), (326, 250) — 벽을 타고 도는 공을 안쪽으로 |
| 센서 | 위쪽 3개, 통과 시 50점·불 켜짐, 셋 다 켜지면 1000점 + 배수 +1 (최대 ×5) |
| 발사 | 스페이스를 누른 시간(최대 60틱) → (6 + 0.12 × 틱) × (0.97~1.03). 최대치가 속도 상한보다 낮아야 시드 효과가 살아 있음 (회귀 테스트) |
| 종료 | 공 3개를 모두 잃거나 15분(108,000틱) |

## 화면 (`apps/site/src/pages/pinball`)
- 조작: ←/Z 왼쪽, →// 오른쪽, 스페이스(↓, Enter) 누르고 있다 떼면 발사. 터치 화면은 아래 버튼 3개
- 그리기는 화면 주사율, 시뮬레이션은 120Hz 고정 틱. 탭이 멈췄다 돌아오면 한 번에 최대 30틱만 따라잡음 (게임 시간이 실제 시간보다 길어지지 않게)
- 서버에 연결할 수 없으면 연습 모드(무작위 시드, 제출 없음)
- 점수판: 오늘(KST 자정 기준) / 전체 상위 10

## 테스트
- Rust: 방향 표 길이, 발사 전 공이 레인에 머묾, 최대 발사로 플레이 영역 진입, 플리퍼가 공을 쳐 올림, 범퍼·배수, 센서 보너스, 결정성·시드 의존, 공이 테이블 밖으로 안 나감, 기둥, 입력 검증, 15분 제한
- TS: Rust 기준값과 50틱마다 공 위치·속도·점수가 비트 단위로 같음, `replay` 결과 같음
- API: 서버 계산 점수 저장(브라우저 주장 무시), 재제출 409, 즉시 제출한 긴 게임 거부, 잘못된 입력 거부
