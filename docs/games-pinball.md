# 핀볼 게임 (설계 초안 · 5단계)

## 구성
- 렌더링: HTML5 Canvas, 물리: Matter.js (고정 타임스텝 1/120초)
- 요소: 플런저(발사), 좌우 플리퍼, 범퍼, 슬링샷, 레인/슬롯, 배수구

## 점수 검증
클라이언트가 물리를 돌리므로 점수를 그대로 믿지 않습니다.
1. 게임 시작 시 서버가 `session_id`, 테이블 버전, `seed`(범퍼 배치·보너스용)를 발급
2. 클라이언트는 점수 이벤트 시퀀스 `[{ t_ms, kind, target, delta }]` 와 입력 로그(플리퍼 누름 타임스탬프)를 기록
3. 종료 시 최종 점수 + 시퀀스를 전송 → 서버 검증
   - 각 이벤트의 `delta` 가 `kind` 별 점수표와 일치하는지
   - 시간이 단조 증가하고 실제 경과 시간(서버 시작~종료) 이내인지
   - 이벤트 간 최소 간격 · 초당 최대 이벤트 수 등 물리적으로 가능한 범위인지
   - 합계 == 최종 점수
4. 의심 점수는 저장하되 랭킹에서 제외하고 플래그
